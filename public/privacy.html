慢记隐私说明

更新日期：2026-11-26

慢记（slowlyRecord）是本地优先的记忆训练工具，没有账号系统。学习数据默认保存在你使用的设备上； 只有在主动使用翻译、OCR、同步或反馈时，才会向对应服务发送必要数据。

1. 保存在本机的数据

  • 词库、单词、复习等级、打卡记录、文本/数字/知识记忆内容。
  • 设置项、界面偏好、自定义背景图。
  • 你填写的翻译 / OCR API Key（uTools 端以 AES-GCM 加密形式随 uTools 账号同步，见第 4 节），以及上次同步生成的同步码。

Web 和小程序端使用浏览器或平台的本地存储（IndexedDB / localStorage / Storage）； uTools 与桌面端使用本地数据库文件。这些数据不会自动上传，除非你主动开启同步或使用在线功能。

2. 匿名使用统计（默认关闭）

为判断版本分布和功能是否有人使用，慢记提供可选的匿名使用统计，默认关闭： 首次启动会明确告知；只有你在告知弹窗或「设置 → 常规设置」底部主动勾选开启后才会上报， 取消勾选立即停止，插件升级不会重新开启（你的选择会持久保存）。

开启后上报的内容仅限：

  • 应用启动、页面浏览、功能使用次数（如添加单词、导入词库、打开设置）。
  • 平台标识、应用版本、匿名安装 ID（首次使用时在本机随机生成，清除本机数据后重置，不读取设备标识）。
  • 程序异常的类型与脱敏、截断后的错误消息（去除 URL 与接口回显，只留首行）；不包含堆栈、词库内容或翻译原文。

统计发送到开发者自建的采集服务（自有域名 stats.slowrecap.cn，背后是腾讯云函数，仅记录访问日志），不经过任何第三方统计平台。 客户端与服务端均按字段白名单收口：不包含词库内容、释义、学习记录、API Key、联系方式或任何输入内容， 服务端不记录 IP 地址。日志保留不超过 7 天，你可以在「设置 → 常规设置」底部随时关闭。

3. 翻译与 OCR

当你翻译单词或识别图片时，输入的文本或图片会发送给当前选择的第三方引擎 （例如 B站 Index-Translate、Google、智谱 GLM、讯飞、百度、有道、腾讯等）。 使用哪个引擎由你在设置中选择，数据也受该服务自己的隐私政策约束。

你自行填写的 API Key 保存在本机；uTools 端会以 AES-GCM 加密形式随 uTools 账号同步到你的各台设备（同步通道与存储由 uTools 平台提供），解密只在设备本地进行。密钥只会随请求发送给对应服务商，不会发送给慢记作者。 内置的共享免费额度由「设置 → 高级设置」中的开关控制（uTools 商店版默认关闭，需手动开启）， 开启时首次使用会弹窗告知数据流向，待翻译文本会发送给对应服务商。

单词发音默认使用系统本地语音合成；英语发音可能向你选择的词典服务（当前为有道 dictvoice）请求单词音频，仅发送单词本身。 文本记忆的水墨地图在你主动打开「地图」标签时，会向高德地图（autonavi.com）请求地图瓦片，仅包含常规瓦片坐标，不含你的学习内容。 划词、剪贴板与截图内容只在你主动触发对应功能（划词添加/翻译、截图 OCR、粘贴）时读取一次，不会被持续监听或自动上传。

4. 多端同步

uTools 端的学习数据与设置由 uTools 平台随账号自动同步（这是 uTools 插件的平台机制）；其中你填写的 API Key 在本机加密后才会进入同步存储，云端只保存密文。记忆宫殿桩图、数字/字母映射图片、自定义背景图等图片内容与外置词典只保存在本机，不参与账号同步。

同步功能在你主动点击时执行：数据先在本地加密，再上传到同步服务；服务端保存的是密文， 解密所需密钥包含在同步码中，由你自行保存。服务端可能按清理策略使旧同步数据过期， 请同时保留本地或 WebDAV 备份。

WebDAV 备份由你自行配置，文件直接写入你指定的网盘，不经过慢记的同步服务。

5. 反馈

通过「设置 → 问题反馈」提交时，反馈内容、可选的联系方式、平台与版本会经统计服务 发送给开发者，仅用于定位和修复问题。反馈提交不受统计开关限制，这是用户主动发起的动作。

6. 数据导出与删除

  • 可以在应用内导出词库或完整备份。
  • 清除浏览器站点数据会删除本机数据且无法恢复，操作前请先导出备份。
  • uTools / 桌面端的数据随插件或应用的数据目录管理；卸载前请先导出备份。
  • 已上传的同步密文可等待服务端过期；如需协助，请通过下方渠道联系。

7. 联系我们

隐私问题、内容移除请求或安全问题，请通过 GitHub Issues 联系。

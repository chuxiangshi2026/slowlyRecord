# 慢记工具 - 全平台记忆训练工具

## 软件简介

**慢记工具**是一款基于**艾宾浩斯遗忘曲线**开发的智能记忆训练工具。不局限于背单词，更支持听写练习、数字记忆、文本/诗词背诵、记忆宫殿（轨迹法）、知识库（内置题包）、快捷键记忆、音标学习、字母映射等多元记忆场景。支持 uTools 插件、Electron 桌面应用、Web 浏览器、微信小程序、Android/iOS App 五大平台，学习进度可在多端之间同步。

### 核心特点

- **科学记忆算法**：基于艾宾浩斯遗忘曲线，自动安排复习计划，14 个等级间隔科学递进
- **单词学习**：支持输入、划词、划段、截图（OCR）等多种添加方式，内置 CET-4/6、考研、托福、雅思等英语词库与 JLPT N5 日语词库，支持单词筛选、切换词库、词根词缀高亮
- **多语言学习**：同一套应用支持英语、日语、俄语、西班牙语、法语——语言按词库设置，翻译、发音（TTS）、听写、拼写、截图 OCR 全链路跟随当前词库语言；非英语 Tesseract OCR 语言包首次使用时按需下载
- **听写与拼写**：播放发音进行听写与拼写练习，检验听力与拼写能力，进度自动保存
- **多引擎翻译**：支持有道、百度、阿里、腾讯、DeepSeek、Kimi、通义千问、智谱 GLM、MiniMax、腾讯混元、uTools AI、Ollama 本地模型等十余种翻译引擎
- **离线使用**：支持本地词典，无网络也能正常使用
- **专注模式**：迷你悬浮窗（间隙学习不打扰），支持置顶、贴边、锁定、透明度调节、字体颜色、字号、背景图片自定义
- **数字记忆**：通过图像关联法（数字编码）高效记忆长串数字，支持一键导入预设编码、映射表导出打印、自定义条目与训练考核
- **文本记忆**：长篇文本、诗词、知识点的分段记忆与背诵练习，支持时间线整理、地理关联、打字/填空/关键词练习、悬浮滚动播放、心得笔记
- **记忆宫殿**：基于轨迹法（位置记忆法），内置 8 套桩库一键导入生成桩位，支持桩图配图、批量解绑与按桩回忆
- **知识库**：36 个内置知识包（乘法表/元素周期表/高等数学/理化公式/朝代/节气/生肖等），翻卡、反向、四选一、输入、顺序回忆五种练习模式，公式条目支持函数图像与现象动画
- **快捷键记忆**：双拼、五笔、数字小键盘、系统/开发软件快捷键练习，支持分类筛选与双拼键位显示
- **音标学习与字母映射**：音标辨音、音素拆解等训练（数据集随当前语言切换：英语音标/日语五十音/俄语西里尔字母等），字母-图片映射联想记忆（各语言字母表）
- **记忆测试**：词汇量预测与记忆效果检验
- **数据安全**：本地数据库存储，支持导入导出；多端同步覆盖单词、文本、数字、快捷键、音标、知识库等学习进度
- **全平台覆盖**：uTools / Electron / Web / 微信小程序 / Android / iOS

## 安装与启动

### 环境要求

- **Node.js** >= 18
- **uTools** 软件（Windows / macOS / Linux）- 用于 uTools 插件版本

### 安装依赖

```bash
npm install
```

### 各平台构建

```bash
# uTools 插件
npm run build

# Electron 桌面版
npm run build:electron
npm run pack:electron

# Web 版
npm run build:web

# 微信小程序
cd mobile && npm install
npm run build:mp-weixin

# Android App
npm run build:app-android

# iOS App
npm run build:app-ios
```

### uTools 插件安装

1. 下载并安装 [uTools](https://u.tools/)
2. 在 uTools 插件市场搜索"慢记工具"或"慢记单词本"
3. 点击安装插件
4. 安装完成后，按 `Alt + 空格` 呼出 uTools，输入 `慢记` 或 `mj` 即可使用

## 添加单词

![添加单词](images/手动添加单词.png)

### 1. 输入添加

1. 呼出 uTools，输入任意单词（如 `apple`）
2. 选择"**加入单词簿**"
3. 系统自动翻译并弹出翻译结果
4. 点击确认即可加入学习列表

### 2. 划词添加

1. 选中任意文本（单词或短语）
2. 呼出 uTools，输入 `划词添加` 或 `hc`
3. 选择翻译引擎，确认后自动添加

### 3. 划段添加

1. 选中一段文字
2. 呼出 uTools，输入 `划段添加`
3. 系统会将段落自动拆分为单词并加入学习列表

![划段添加](<images/划段添加.jpg>)

### 4. 截图添加

1. 呼出 uTools，输入 `截图添加` 或 `ss`
2. 截取包含文字的图片区域
3. 系统自动 OCR 识别图片中的文字
4. 选择需要添加的单词，确认后添加

![截图添加](<images/截图添加.jpg>)

> **注意**：截图翻译每日限制 5-10 次（未配置个人密钥时）。配置自己的密钥后可无限使用。

## 单词复习

![单词筛选](images/单词筛选.png)

![单词复习列表](images/单词复习列表.png)

### 进入复习模式

呼出 uTools，输入 `mj`、`慢记` 或 `review`，进入单词列表界面。

### 复习界面说明

| 区域 | 说明 |
|------|------|
| **单词卡片** | 显示单词、音标（词根词缀颜色区分）、发音按钮、等级标签 |
| **释义区** | 显示中文释义与例词，可编辑 |
| **操作按钮** | 播放 / 翻译 / 认识 / 忘记 / 已记完 / 删除 |
| **筛选排序** | 支持通配符搜索、长度、词根词缀、音标、类型筛选与 A-Z/长度/时间/等级排序 |
| **词库切换** | 左下角点击当前词库名，支持多词库切换学习 |

### 复习操作

| 操作 | 说明 | 快捷键 |
|------|------|--------|
| **播放发音** | 点击喇叭图标播放美式发音 | `Shift + P` |
| **翻译** | 查看单词翻译释义 | `Shift + T` |
| **认识** | 标记为已掌握，升级复习等级 | `Shift + R` |
| **忘记** | 标记为忘记，降低复习等级 | `Shift + F` |
| **已记完** | 锁定标记，该单词不再出现在待复习列表 | 卡片锁形按钮 |
| **删除** | 从当前词库移除该单词 | 卡片删除按钮 |
| **保存释义编辑** | 编辑释义后保存 | `Ctrl + Enter` |

| 4 | 6 小时 | 第四次复习 |
| 5 | 12 小时 | 第五次复习 |
| 6 | 1 天 | 第六次复习 |
| 7 | 2 天 | 第七次复习 |
| 8 | 4 天 | 第八次复习 |
| 9 | 1 周 | 第九次复习 |
| 10 | 半个月 | 第十次复习 |
| 11 | 1 个月 | 第十一次复习 |
| 12 | 3 个月 | 第十二次复习 |
| 13 | 半年 | 第十三次复习 |
| 14 | 1 年 | 第十四次复习 |

> 达到等级 7 及以上的单词自动标记为"**永久记住**"，可在"已记完"列表中查看。

## 听写模式

![听写模式](images/听写模式.png)

### 功能说明

听写模式通过播放单词发音，让用户拼写单词，检验听力与拼写能力。

### 使用方法

1. 在单词列表界面，点击"**听写模式**"按钮
2. 系统开始播放单词发音
3. 用户根据发音输入单词
4. 输入完成后回车确认，查看结果

### 听写设置

- **范围选择**：可选择全部单词、待复习单词、指定等级单词
- **播放次数**：设置每个单词发音播放次数
- **自动下一题**：答对后自动播放下一题
- **保存进度**：自动保存听写进度，下次可从上次位置继续

## 专注模式

![专注模式](images/专注模式.png)

### 功能说明

专注模式提供一个极简的悬浮窗口，让用户在工作学习间隙快速复习单词。支持多种复习模式（标准/拼写/听写）。

### 进入方式

在单词列表界面，点击"**专注模式**"按钮，或从听写练习页面跳转。

### 功能特性

| 功能 | 说明 |
|------|------|
| **置顶显示** | 窗口始终保持在最前 |
| **贴边隐藏** | 贴边时自动隐藏，鼠标靠近时展开 |
| **透明度调节** | 可调节窗口透明度（30%-100%） |
| **锁定模式** | 锁定后内容区鼠标穿透，仅顶部按钮可点击 |
| **拼写模式** | 键盘逐个字母拼写单词 |
| **听写模式** | 根据发音输入单词拼写 |
| **样式自定义** | 可设置字体颜色、单词字号、释义字号、背景图片 |

### 样式设置

在设置抽屉的"**专注模式设置**"区域，可自定义：

| 设置项 | 范围 | 说明 |
|--------|------|------|
| **字体颜色** | 任意色 / 跟随主题 | 单词和释义的文字颜色 |
| **单词字号** | 14-40 px | 单词主体的字号 |
| **释义字号** | 9-24 px | 中文释义的字号 |
| **背景图片** | 图片文件（≤2MB） | 窗口背景图片，data URL 持久化 |
| **背景透明度** | 0-100% | 背景图片的叠加透明度 |

> 修改后实时生效，无需关闭专注窗口。背景图不会覆盖透明度背景，贴边隐藏时自动隐藏。

## 音标学习

![音标学习](images/音标学习.png)

### 功能说明

提供各语言发音单元的系统学习和练习，支持四种训练模式。按当前词库语言自动切换数据集：英语 48 个国际音标、日语五十音（清音/浊音/拗音共 103 条）、俄语 33 个西里尔字母、西班牙语/法语发音精简集。学习进度按语言独立保存。

### 入口

单词页底部工具栏的「音标学习」图标按钮（🎤），进入 `/phonetic-memory` 路由。侧边栏无独立入口。

### 训练模式

| 模式 | 说明 |
|------|------|
| **音标识别** | 看音标 → 选例词（正向练习） |
| **反向识别** | 看单词 → 选音标（反向练习） |
| **最小对立对** | 听发音 → 二选一（辨别相似音） |
| **音素拆解** | 单词 → 拆解为各个音素 |

### 音标表

- 元音：单元音、双元音（共 20 个）
- 辅音：爆破音、摩擦音、破擦音、鼻音、半元音、舌侧音（共 28 个）
- 支持按分组查看、点击播放发音、跟踪掌握进度

## 数字记忆训练

![数字记忆首页](images/数字记忆首页.png)

### 功能说明

数字记忆训练帮助你将 0-99 的每个数字关联到具体图像/关键词（如 15=鹦鹉、61=六一儿童节），利用图像编码法大幅提升长串数字的记忆效率。支持一键导入预设编码、映射表整图导出与打印，并提供条目管理与训练考核。

### 入口

侧边栏「数字记忆」或 `/number-memory` 路由。呼出 uTools 输入 `数字记忆` 也可进入。

### 功能模块

首页分为四个区域：

**① 训练**（三种训练模式）

![数字记忆训练](images/数字记忆训练.png)

- **数字 → 图片**：看到数字，选择对应的关联图片
- **图片 → 数字**：看到图片，选择对应的数字
- **随机序列**：限时记忆随机数字串，逐级加长

> 前两种模式需先保存至少 4 个数字-图片关联；训练自动计时并统计正确率与用时，支持训练历史查看。

**② 管理**

- **数字记忆条目**：自由创建数字记忆条目（标题 + 数字 + 助记口诀 + 标签 + 描述），适合电话号码、纪念日等真实场景，支持搜索、标签筛选、到期复习与图片关联

![数字记忆条目](images/数字记忆条目.png)

- **数字-图片映射设置**：按范围（个位数/前导零/两位数/全部 0-99）为每个数字选择预设图片或上传自定义图片，支持「一键导入预设」，并可将整张映射表导出为图片或打印

![数字映射设置](images/数字映射设置.png)

**③ 训练历史**：查看历史训练记录、正确率与用时。

**④ 知识表**：直接浏览/导入数学类知识包（乘法表、公式、元素周期表等），与「知识库」模块互通。

### 使用方法

## 记忆宫殿

### 功能说明

记忆宫殿（轨迹法）将需要记忆的内容与熟悉空间中的固定位置（"桩"）绑定，是公认最高效的记忆法之一。慢记工具内置桩库导入、桩位编辑、桩图配图与按桩回忆四件套，零基础也能快速搭建自己的宫殿。

### 入口

文本记忆页（侧边栏「文本记忆」）顶部的视图切换标签 →「记忆宫殿」（`/text-memory?view=palace`）。侧边栏没有独立的记忆宫殿入口。

从宫殿列表可进入三个子页面：详情 `/memory-palace/:id`、编辑 `/memory-palace/edit/:id`、巡视 `/memory-palace/:id/review`。

### 功能模块

**① 宫殿列表**（MemoryPalace）

![记忆宫殿列表](images/记忆宫殿列表.png)

- 管理多个独立宫殿（如「家居路线」「学校教室」）
- 每个宫殿显示桩位数、创建时间、复习进度
- 支持新建、编辑、删除、进入复习

**② 桩库导入**（内置桩库 → 一键转桩）
- 内置桩库（usableAsPeg 知识包）：数字桩、家居路线桩、二十四节气、十二生肖、身体桩、十二地支、房间桩、中国历代王朝等
- 导入时自动按条目顺序生成桩位，并把条目配图（emoji）转成桩图 dataURL
- 也支持手动逐个添加桩位

**③ 桩位编辑**（编辑页）

![记忆宫殿编辑](images/记忆宫殿编辑.png)

- 拖拽排序、增删桩位、为每个桩上传/替换图片
- 桩图支持 emoji 默认图与自定义照片（自动压缩为 dataURL 持久化）

**④ 宫殿详情**（详情页）

![记忆宫殿详情](images/记忆宫殿详情.png)

- 桩图网格预览、桩位列表
- 批量解绑桩图、单桩重置
- 进入复习

**⑤ 按桩回忆**（复习页）

![记忆宫殿巡视](images/记忆宫殿巡视.png)

- 按桩位顺序逐个回忆关联内容
- 正向/反向回忆、自动计时与正确率统计

### 使用方法

1. 在宫殿列表点击「新建」，输入名称
2. 编辑页选择「导入桩库」→ 选内置桩库（如家居路线桩）→ 自动生成 12 个带默认图的桩位
3. 可逐个替换桩图为真实场景照片，加深空间记忆
4. 返回详情页，点击「开始复习」按桩位回忆

### 适用场景

- 背诵长篇演讲稿（每个桩挂一段）
- 记忆历史朝代顺序、二十四节气顺序
- 应试知识点的空间编码（医学/法考/考研）

## 快捷键记忆

![快捷键领域](images/快捷键领域.png)

![快捷键分类](images/快捷键分类.png)

![快捷键列表](images/快捷键列表.png)

### 功能说明

快捷键记忆帮助用户快速掌握常用软件的快捷键操作，并支持五笔、双拼等输入法的键位与编码练习。提供按键训练、反向训练、错题训练三种模式，配合专项标签筛选与学习进度追踪。

### 入口

侧边栏「快捷键记忆」或 `/shortcut-memory` 路由（仅桌面环境）。

### 使用方法

1. **选择领域**：先选择快捷键所属领域（系统、开发、办公、设计、财务、输入法）
2. **选择分类**：在领域下选择具体分类（如 VS Code、五笔86版、双拼 · 小鹤）
3. **筛选标签**（可选）：对支持专项标签的分类，按「类型 + 分区」两维组合筛选练习范围
4. **开始训练**：从快捷键列表发起训练，结束后查看正确率与用时

### 训练模式

| 模式 | 说明 |
|------|------|
| **🎯 按键训练** | 显示功能名称，按下对应快捷键；组合键（Ctrl+C）同时按、顺序键（五笔/双拼编码）逐键顺序输入 |
| **🔄 反向训练** | 显示快捷键组合，从选项中选择对应的功能描述 |
| **⚠️ 错题训练** | 针对该分类下答错的条目专项重练 |

> 训练中点击「返回」会回到查看页并**保留**之前选定的领域、分类与标签筛选，无需重新选择。

### 专项标签筛选

部分分类（五笔、双拼）的条目带有专项标签，可在查看列表与训练中按需筛选：

- **类型**：字根、一级简码、二级简码、常用字、一级词组、二级词组、成语、键名字、万能键
- **分区**（五笔字根按首笔划分）：横区、竖区、撇区、捺区、折区

两维可组合使用，例如「一级简码 + 横区」只练横区的高频单键字。其中：

| 类型标签 | 说明 |
|----------|------|
| **一级简码** | 五笔高频单键字（1 键 + 空格），难度最低 |
| **二级简码** | 五笔两键简码字（2 键 + 空格） |
| **常用字** | 高频常用字（含一、二级简码） |
| **一级词组 / 二级词组** | 词组按常见度拆分两级，便于分级练习 |
| **字根** | 五笔字根（按键位分区） |
| **键名字** | 五笔键名字根 |
| **成语** | 四字成语编码 |

### 输入法练习

五笔（86/98 版）与双拼（小鹤、自然码、微软、搜狗）分类除键位/字根外，还运行时生成常用字、词组、一级简码等编码练习条目。输入法分类额外提供「🔤 悬浮键盘」按钮，可调出键位映射悬浮窗辅助对照（仅 uTools 桌面端）。

### 支持分类

| 领域 | 分类 |
|------|------|
| **系统** | Windows、键位练习、数字小键盘练习 |
| **开发** | VS Code、Chrome、IntelliJ IDEA、Vim、Claude Code CLI |
| **办公** | Word、Excel、PowerPoint、Outlook、Obsidian、思源笔记 |
| **设计** | Photoshop、Illustrator、CAD |
| **财务** | 数字小键盘练习 |
| **输入法** | 五笔86版、五笔98版、双拼 · 小鹤、双拼 · 自然码、双拼 · 微软、双拼 · 搜狗 |
| **自定义** | 用户自建分类 |

> 支持新增自定义分类与快捷键；内置分类可隐藏，自定义分类可编辑/删除/重命名。

## 记忆测试

![记忆测评](images/记忆测评.png)

### 功能说明

记忆测试提供多种模式来评估和锻炼记忆力，包括数字记忆、单词记忆、图案记忆和词汇量测试四种模式。

### 入口

侧边栏「记忆测试」入口，或呼出 uTools 输入 `记忆测试`。

### 测试模式

| 模式 | 说明 |
|------|------|
| **数字记忆** | 显示一串数字后消失，凭记忆输入。支持简单（4位）、中等（6位）、困难（8位）三级难度，多轮递进 |
| **单词记忆** | 显示一组单词后消失，凭记忆列出。按轮次增加单词数量，测试短期词汇记忆能力 |
| **图案记忆** | 在网格中亮起若干格子后复原，按轮次增加格子数量，测试空间记忆能力 |
| **词汇量测试** | 按当前语言选择等级阶梯：英语 CET-4/6、雅思、托福、GRE；日语 JLPT N5~N1；俄/西/法 CEFR A1~C2 |

### 使用方法

1. 选择测试模式（数字/单词/图案/词汇量）
2. 选择难度级别
3. 点击"开始测试"
4. 按提示完成各轮测试
5. 查看测试结果报告

### 词汇量测试

词汇量测试是独立子模块，通过多级抽样准确估算词汇量：

| 功能 | 说明 |
|------|------|
| **测试轮数** | 可选快速（3轮/约5分钟）、标准（5轮/约8分钟）、精确（7轮/约12分钟） |
| **每轮词数** | 每轮 5-15 个单词可调 |
| **智能分级** | 基于多级词库（CET4→CET6→考研→雅思→托福→GRE）逐步提升难度 |

## 多端同步

![多端同步](images/多端同步.png)

### 功能说明

支持跨设备数据同步。在单词列表界面点击底部工具栏的"**多端同步**"图标打开同步面板，包含两种方式：

**① 服务器同步（推荐）**

- **端到端加密**：数据在本地 AES-256 加密后才上传，服务器只存密文无法解读
- **推送数据**：将当前设备数据加密上传，生成一次性**同步码**
- **拉取数据**：在另一台设备输入同步码即可下载还原
- 可推送/拉取**桌面端**与**移动端**（微信小程序）数据；小程序可扫码直接进入
- 默认使用官方中转服务器，也可在「自定义服务器」中替换为自建服务器（可检测服务器状态）

**② 文件同步**

- 导出/导入数据文件，通过任意渠道传输完成同步，适合无服务器环境

### 同步内容

- 所有词库及单词数据
- 文本记忆、数字记忆、快捷键记忆、字母映射数据
- 用户设置（翻译引擎、记忆牢固度、专注模式配置等）

## 常见问题

### Q1: 为什么截图翻译有次数限制？

截图翻译涉及 OCR 识别和翻译 API 调用，成本较高。未配置密钥时，每日限制 5-10 次。建议配置自己的 API 密钥，可享受免费额度。

### Q2: 如何离线使用？

在设置中选择"**本地词典**"作为翻译引擎，无需网络即可查词。但本地词典词汇量有限，建议配合在线引擎使用。

### Q3: 数据存储在哪里？

所有数据存储在本地数据库中，不会上传到云端。重装系统前请记得导出备份。

### Q4: 如何同步多台设备的数据？

在单词列表底部工具栏点击"**多端同步**"，推荐使用**服务器同步**：设备 A「推送数据」生成同步码，设备 B 输入同步码「拉取数据」即可完成（数据全程 AES-256 加密）。无服务器环境可使用**文件同步**：
1. 在设备 A 导出数据文件
2. 将文件传输到设备 B
3. 在设备 B 导入文件

### Q5: 为什么有些单词没有发音？

请检查：
1. 网络连接是否正常
2. 发音引擎设置是否正确
3. 是否启用了离线发音

### Q6: 如何更换主题？

插件自动适配 uTools 的主题设置。在 uTools 设置中切换浅色/深色主题，插件会自动跟随切换，支持暗黑模式。

### Q7: 添加单词后没有出现在列表中？

请检查：
1. 是否正确点击了"确认添加"
2. 列表筛选条件是否设置为"全部"
3. 是否开启了"只显示待复习"筛选

### Q8: 如何删除单词？

在单词列表中，点击单词卡片上的删除按钮。

### Q9: 如何切换词库？

在单词列表界面，点击底部"**当前词库名**"打开词库管理器，选择需要学习的词库。词库数据独立存储，切换后显示对应词库的单词。

### Q10: 听写模式如何保存进度？

听写模式会自动保存当前进度，下次进入时会询问是否继续上次的听写。也可在听写设置中关闭自动保存。

### Q11: 专注模式字体/背景设置为什么不生效？

请确认：
1. uTools 开发者工具的"资源目录"指向当前正确的项目 dist 目录
2. 修改设置后无需关闭专注窗口，设置实时生效
3. 如使用打包版本，需执行 `npm run build` 更新插件

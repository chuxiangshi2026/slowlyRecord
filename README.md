# 慢记工具 - 全平台记忆训练工具

## 软件简介

**慢记工具**是一款基于**艾宾浩斯遗忘曲线**开发的智能记忆训练工具。不局限于背单词，更支持数字记忆、文本/诗词背诵、快捷键记忆、音标学习等多元记忆场景。支持 uTools 插件、Electron 桌面应用、Web 浏览器、微信小程序、Android/iOS App 五大平台。

### 核心特点

- **科学记忆算法**：基于艾宾浩斯遗忘曲线，自动安排复习计划，14 个等级间隔科学递进
- **数字记忆**：通过图像关联法（数字编码）高效记忆长串数字，支持自定义条目与训练考核
- **文本记忆**：长篇文本、诗词、知识点的分段记忆与背诵练习，支持标签分类与地图标记
- **单词学习**：支持输入、划词、划段、截图等多种方式添加单词，内置 CET-4/6、考研、托福、雅思等权威词库
- **多引擎翻译**：支持有道、百度、阿里、腾讯、DeepSeek、Kimi、通义千问、智谱 GLM、uTools AI、OpenAI、Gemini、Claude、Ollama 本地模型等十余种翻译引擎
- **离线使用**：支持离线词典，无网络也能正常使用
- **专注模式**：迷你悬浮窗口，支持置顶、贴边、锁定、透明度调节、字体颜色、字号、背景图片自定义
- **多元记忆**：支持单词、数字、文本、快捷键、音标、字母映射等多种记忆训练
- **数据安全**：本地数据库存储，支持导入导出、多端数据同步
- **全平台覆盖**：uTools / Electron / Web / 微信小程序 / Android / iOS

## 安装与启动

### 环境要求

- **Node.js** >= 18
- **uTools** 软件（Windows / macOS / Linux）- 用于 uTools 插件版本

### 安装依赖

```bash
npm install
```

### 各平台构建

```bash
# uTools 插件
npm run build

# Electron 桌面版
npm run build:electron
npm run pack:electron

# Web 版
npm run build:web

# 微信小程序
cd mobile && npm install
npm run build:mp-weixin

# Android App
npm run build:app-android

# iOS App
npm run build:app-ios
```

### uTools 插件安装

1. 下载并安装 [uTools](https://u.tools/)
2. 在 uTools 插件市场搜索"慢记工具"或"慢记单词本"
3. 点击安装插件
4. 安装完成后，按 `Alt + 空格` 呼出 uTools，输入 `慢记` 或 `mj` 即可使用

## 添加单词

### 1. 输入添加

1. 呼出 uTools，输入任意单词（如 `apple`）
2. 选择"**加入单词簿**"
3. 系统自动翻译并弹出翻译结果
4. 点击确认即可加入学习列表

### 2. 划词添加

1. 选中任意文本（单词或短语）
2. 呼出 uTools，输入 `划词添加` 或 `hc`
3. 选择翻译引擎，确认后自动添加

### 3. 划段添加

1. 选中一段文字
2. 呼出 uTools，输入 `划段添加`
3. 系统会将段落自动拆分为单词并加入学习列表

### 4. 截图添加

1. 呼出 uTools，输入 `截图添加` 或 `ss`
2. 截取包含文字的图片区域
3. 系统自动 OCR 识别图片中的文字
4. 选择需要添加的单词，确认后添加

> **注意**：截图翻译每日限制 5-10 次（未配置个人密钥时）。配置自己的密钥后可无限使用。

## 单词复习

### 进入复习模式

呼出 uTools，输入 `mj`、`慢记` 或 `review`，进入单词列表界面。

### 复习界面说明

| 区域 | 说明 |
|------|------|
| **单词卡片** | 显示单词、音标（词根词缀颜色区分）、发音按钮 |
| **释义区** | 显示中文释义，可隐藏/显示 |
| **操作按钮** | 认识 / 模糊 / 忘记、置顶、置底、永久记住 |
| **单词筛选** | 支持按复习状态、等级、长度、通配符、词根词缀筛选 |
| **词库切换** | 支持多词库切换学习 |

### 复习操作

| 操作 | 说明 | 快捷键 |
|------|------|--------|
| **播放发音** | 点击喇叭图标播放美式发音 | `Ctrl + P` |
| **显示/隐藏释义** | 点击眼睛图标切换 | `Ctrl + H` |
| **认识** | 标记为已掌握，升级复习等级 | `→` / `D` |
| **模糊** | 标记为模糊，保持当前等级 | `↓` / `S` |
| **忘记** | 标记为忘记，降低复习等级 | `←` / `A` |
| **永久记住** | 该单词不再出现在复习列表 | `M` |
| **编辑释义** | 点击编辑按钮修改释义 | `E` |

### 记忆等级说明

单词共有 **14 个等级**，每次有效复习会提升等级，延长下次复习时间：

| 等级 | 复习间隔 | 说明 |
|------|----------|------|
| 1 | 1 分钟 | 第一次复习 |
| 2 | 5 分钟 | 第二次复习 |
| 3 | 30 分钟 | 第三次复习 |
| 4 | 6 小时 | 第四次复习 |
| 5 | 12 小时 | 第五次复习 |
| 6 | 1 天 | 第六次复习 |
| 7 | 2 天 | 第七次复习 |
| 8 | 4 天 | 第八次复习 |
| 9 | 1 周 | 第九次复习 |
| 10 | 半个月 | 第十次复习 |
| 11 | 1 个月 | 第十一次复习 |
| 12 | 3 个月 | 第十二次复习 |
| 13 | 半年 | 第十三次复习 |
| 14 | 1 年 | 第十四次复习 |

> 达到等级 7 及以上的单词自动标记为"**永久记住**"，可在"已记完"列表中查看。

## 听写模式

### 功能说明

听写模式通过播放单词发音，让用户拼写单词，检验听力与拼写能力。

### 使用方法

1. 在单词列表界面，点击"**听写模式**"按钮
2. 系统开始播放单词发音
3. 用户根据发音输入单词
4. 输入完成后回车确认，查看结果

### 听写设置

- **范围选择**：可选择全部单词、待复习单词、指定等级单词
- **播放次数**：设置每个单词发音播放次数
- **自动下一题**：答对后自动播放下一题
- **保存进度**：自动保存听写进度，下次可从上次位置继续

## 专注模式

### 功能说明

专注模式提供一个极简的悬浮窗口，让用户在工作学习间隙快速复习单词。支持多种复习模式（标准/拼写/听写）。

### 进入方式

在单词列表界面，点击"**专注模式**"按钮，或从听写练习页面跳转。

### 功能特性

| 功能 | 说明 |
|------|------|
| **置顶显示** | 窗口始终保持在最前 |
| **贴边隐藏** | 贴边时自动隐藏，鼠标靠近时展开 |
| **透明度调节** | 可调节窗口透明度（30%-100%） |
| **锁定模式** | 锁定后内容区鼠标穿透，仅顶部按钮可点击 |
| **拼写模式** | 键盘逐个字母拼写单词 |
| **听写模式** | 根据发音输入单词拼写 |
| **样式自定义** | 可设置字体颜色、单词字号、释义字号、背景图片 |

### 样式设置

在设置抽屉的"**专注模式设置**"区域，可自定义：

| 设置项 | 范围 | 说明 |
|--------|------|------|
| **字体颜色** | 任意色 / 跟随主题 | 单词和释义的文字颜色 |
| **单词字号** | 14-40 px | 单词主体的字号 |
| **释义字号** | 9-24 px | 中文释义的字号 |
| **背景图片** | 图片文件（≤2MB） | 窗口背景图片，data URL 持久化 |
| **背景透明度** | 0-100% | 背景图片的叠加透明度 |

> 修改后实时生效，无需关闭专注窗口。背景图不会覆盖透明度背景，贴边隐藏时自动隐藏。

### 专注模式快捷键

| 快捷键 | 功能 |
|--------|------|
| `Shift + R` | 认识（升级） |
| `Shift + F` | 忘记（降级） |
| `Shift + P` | 播放发音 |
| `Shift + T` | 显示/隐藏释义 |
| `↓` | 永久记住 |
| `←` | 上一个单词 |
| `→` | 下一个单词 |
| `Ctrl + L` | 锁定/解锁（鼠标穿透） |
| `Esc` | 关闭专注窗口 |

文本记忆页文章菜单「专注显示」打开的文本滚动浮窗，快捷键如下：

## 音标学习

### 功能说明

提供英语 48 个国际音标的系统学习和练习，支持四种训练模式。

### 入口

侧边栏「音标学习」图标或 `/phonetic-memory` 路由。

### 训练模式

| 模式 | 说明 |
|------|------|
| **音标识别** | 看音标 → 选例词（正向练习） |
| **反向识别** | 看单词 → 选音标（反向练习） |
| **最小对立对** | 听发音 → 二选一（辨别相似音） |
| **音素拆解** | 单词 → 拆解为各个音素 |

### 音标表

- 元音：单元音、双元音（共 20 个）
- 辅音：爆破音、摩擦音、破擦音、鼻音、半元音、舌侧音（共 28 个）
- 支持按分组查看、点击播放发音、跟踪掌握进度

## 数字记忆训练

### 功能说明

数字记忆训练帮助你将 0-99 的每个数字关联到具体图像/关键词（如 15=鹦鹉、61=六一儿童节），利用图像编码法大幅提升长串数字的记忆效率。系统预设了常用编码表，也支持完全自定义。

### 入口

侧边栏「数字记忆」或 `/number-memory` 路由。呼出 uTools 输入 `数字记忆` 也可进入。

### 功能模块

数字记忆分为三个主要区域：

**① 数字选择区**（主页面）
- 按范围筛选：个位数 (0-9)、前导零 (00-09)、两位数 (10-99)、全部 (0-99)
- 为每个数字选择/设置关联图像（从预设库选择或上传自定义图片）
- 支持一键导入主流编码预设（如多米尼克系统、记忆宫殿编码等）
- 查看已关联的数字进度

**② 条目管理**（`📝 数字记忆`）
- 自由创建数字记忆条目：标题 + 数字 + 关联内容 + 标签
- 支持搜索和按标签筛选
- 每条记录可自由编辑和删除

**③ 训练考核**（`🎯 开始训练`）
- **数字→图片模式**：看到数字，选择对应的关联图片
- **图片→数字模式**：看到图片，选择对应的数字
- 支持继续未完成的训练进度
- 自动计时、统计正确率与用时
- 查看训练历史记录

### 使用方法

1. 进入数字记忆页面，选择数字范围（如 0-99）
2. 为数字逐一点击选择关联图像，或点击"一键导入预设"
3. 至少关联 4 个数字后，点击"开始训练"
4. 在训练中选择模式，系统随机出题考核
5. 查看训练报告与历史记录

### 适用场景

- 记忆长串电话号码、银行卡号
- 记忆圆周率、历史年份等数字序列
- 提升日常数字敏感度
- 锻炼图像联想能力

## 文本记忆

### 功能说明

文本记忆是**慢记工具的核心功能之一**，支持诗词、文章、知识点等任意长文本的导入、管理与多种记忆练习。不同于背单词的短时记忆，文本记忆适合需要逐段背诵的长篇内容。支持按标签分类、按作者检索、地理地图标记。

### 入口

侧边栏「文本记忆」或 `/text-memory` 路由。呼出 uTools 输入 `文本记忆`、`诗词记忆` 或 `wbjy` 也可进入。

### 功能模块

**① 文章管理**
- 列表视图与地图视图可切换
- 支持搜索标题/内容、按标签筛选
- 每篇文章显示标题、作者、摘要、标签、复习次数
- 支持添加、编辑、删除文章

**② 添加方式**
- **手动添加**：输入标题、作者、正文内容
- **批量导入**：支持 TXT/JSON 批量导入（自动按章节/段落拆分）

**③ 练习模式**

| 模式 | 说明 |
|------|------|
| **跟打练习** | 按照原文逐字输入，考验准确打字和记忆还原能力 |
| **填空练习** | 自动挖空关键词，根据上下文填入缺失部分 |
| **选择题** | 系统根据内容自动生成选择题，考核理解程度 |

**④ 辅助功能**

| 功能 | 说明 |
|------|------|
| **笔记** | 为每篇文章添加个人学习笔记 |
| **提示词** | 自定义记忆提示词，帮助回忆关键内容 |
| **地图定位** | 若文章关联地理坐标，可在地图上标注（如诗词创作地点） |
| **诗词地图** | 在地图上浏览所有已标记地点的文章 |

### 使用方法

1. 点击"添加文本"输入或粘贴需要记忆的内容
2. 可设置标题、作者、标签用于分类
3. 在文章列表点击文章，选择练习模式
4. **填空练习**：系统自动挖空，你根据上下文填写
5. **跟打练习**：对照原文打字，提升记忆精度
6. 系统自动记录复习次数，跟踪掌握进度

### 适用场景

- 古诗词背诵（如唐诗三百首）
- 英语范文/演讲稿记忆
- 专业课知识点背诵
- 国学经典、文言文学习
- 法律条文、合同条款记忆

### 导出单词

1. 进入单词列表界面

   - 全部单词

1. 进入单词列表界面
2. 点击"**导入**"按钮
3. 选择导入文件（支持 JSON、TXT）
4. 系统自动解析并导入

### 文件格式说明

#### 格式一：简单格式（仅单词）

每行一个单词，系统会自动查询释义：

```
apple
banana
orange
computer
```

#### 格式二：完整格式（保留状态）

**JSON 格式**：

```json
[
  {
    "text": "apple",
    "explains": "n. 苹果",
    "phonetic": "[ˈæpl]",
    "level": 3,
    "isReview": true,
    "remember": false
  }
]
```

**TXT/CSV 格式**：

```
单词|释义|音标|等级|是否复习|是否记住
apple|n. 苹果|[ˈæpl]|3|true|false
```

## 常见问题

### Q1: 为什么截图翻译有次数限制？

截图翻译涉及 OCR 识别和翻译 API 调用，成本较高。未配置密钥时，每日限制 5-10 次。建议配置自己的 API 密钥，可享受免费额度。

### Q2: 如何离线使用？

在设置中选择"**离线词典**"作为翻译引擎，无需网络即可查词。但离线词典词汇量有限，建议配合在线引擎使用。

### Q3: 数据存储在哪里？

所有数据存储在本地数据库中，不会上传到云端。重装系统前请记得导出备份。

### Q4: 如何同步多台设备的数据？

支持通过自建同步服务器实现多端数据同步（需配置同步服务器地址）。也支持手动同步：
1. 在设备 A 导出单词文件
2. 将文件传输到设备 B
3. 在设备 B 导入文件

### Q5: 为什么有些单词没有发音？

请检查：
1. 网络连接是否正常
2. 发音引擎设置是否正确
3. 是否启用了离线发音

### Q6: 如何更换主题？

插件自动适配 uTools 的主题设置。在 uTools 设置中切换浅色/深色主题，插件会自动跟随切换，支持暗黑模式。

### Q7: 添加单词后没有出现在列表中？

请检查：
1. 是否正确点击了"确认添加"
2. 列表筛选条件是否设置为"全部"
3. 是否开启了"只显示待复习"筛选

### Q8: 如何删除单词？

在单词列表中，点击单词卡片上的删除按钮。

### Q9: 如何切换词库？

在单词列表界面，点击底部"**当前词库名**"打开词库管理器，选择需要学习的词库。词库数据独立存储，切换后显示对应词库的单词。

### Q10: 听写模式如何保存进度？

听写模式会自动保存当前进度，下次进入时会询问是否继续上次的听写。也可在听写设置中关闭自动保存。

### Q11: 专注模式字体/背景设置为什么不生效？

请确认：
1. uTools 开发者工具的"资源目录"指向当前正确的项目 dist 目录
2. 修改设置后无需关闭专注窗口，设置实时生效
3. 如使用打包版本，需执行 `npm run build` 更新插件

# 词集重设计实施计划（2026-11-03）

> 状态：阶段 0～4 核心已完成；拖拽排序、来源释义刷新、移动端移植与激励仍待后续。
> 首发范围：仅 uTools 桌面端；Electron/Web 可复用时顺带受益，移动端暂不移植新 UI。
> 历史文档：`wordbook-redesign-plan-2026-11-02.md` 记录已完成的初版重构，本文定义下一轮方向。

## 1. 最终定位

**词集是由用户自己汇编、编辑、学习和分享学习页的工具。**

系统提供少量示例，让用户进入后即可查看并学会操作；示例不是官方出版内容，不建设严格审校、远程书店或作者订阅体系。

学习页继续以「中心节点 + 周围单词 + 连线」的导图为主要展示形式：

- 字母组合 `old` → `fold / hold / cold / gold`
- 词根 `port` → `import / export / report / transport`
- 发音 `/əʊ/` → `no / know / go / hold / home`

「词集」是功能与内容组织形式，「导图」是学习页的主要展示形式，两者不冲突。

### 核心原则

1. **工具优先**：创建、增删、排序、修改和拆分页面是一级能力。
2. **查看优先**：默认浏览，不强迫用户逐词评分。
3. **复习**：需要自测时隐藏释义，展开后再自评，错词在本轮重现。
4. **导图克制**：每页少量单词，布局服务内容，不为了图而图。
5. **模块独立**：词集不修改主词库内容及其 SRS，不复制主词库功能。
6. **桌面先行**：先验证 uTools 的内容结构与交互，再移植其他端。
7. **激励后置**：关卡、徽章、解锁不作为本期依赖。

## 2. 命名与信息架构

### 用户侧命名

- 功能：**词集**
- 一本书：**一本词集**
- 章：**章节 / 主题**
- 页：**学习页**
- 操作：**新建词集、添加学习页、编辑本页、加入词集、分享词集**
- 中心类型：**字母组合、词根、前缀、后缀、发音、自定义主题**

推荐副标题：「把单词编成自己的学习页，自由编排、复习和分享。」

内部路由、`WordBook` store、DB 前缀和同步字段暂不批量改名，避免无收益的数据迁移。

### 页面结构

```text
词集首页
├─ 继续学习
├─ 示例词集
├─ 我的词集
└─ 新建词集

词集详情
├─ 简介 / 学习进度
├─ 章节目录
└─ 学习页列表

学习页
├─ 顶部：书名、章节、页码、模式切换
├─ 中部：中心导图
├─ 侧边或抽屉：单词详情 / 编辑工具
└─ 底部：上一页、标记已读、下一页
```

## 3. 当前实现必须先处理的问题

### 3.1 创建结果不可靠

- 桌面与移动端输入的学习页名称未用于最终创建，仍使用默认名称。
- 桌面「选择已有书/章」与「输入新建书/章」可能同时有值，导致忽略新名称。
- `watch(bookId)` 可能覆盖从章节带入的锁定目标。
- 批量创建未检查每次保存结果，可能部分成功却提示全部成功。

涉及：`WordBookCreateDialog.vue`、`stores/wordBook.ts`、移动端 `word-book/edit.vue`。

本期只重做桌面创建流程；移动端保留旧实现但停止扩散使用。

### 3.2 当前评分语义不成立

- 「还没记住」后再点「记住了」会删除错误历史。
- 完成要求全部标记，导致最终通常 100 分并升级。
- 任何错误一律降 4 级，错 1 词与错多词惩罚相同。
- 新页面创建后未学习就进入复习倒计时。
- 「再记一遍」可反复推进正式调度。

本期不再把「全部点完」解释成「整页永久掌握」，先建立正确的当轮状态，再保留简单页级复习。

### 3.3 缺少真正的编排能力

目前学习页生成后基本只能重命名、删除，不能添加、移除、排序、修改词条或拆页，无法满足用户自行汇编的定位。

### 3.4 导图布局与学习状态不适合编辑

- 固定 600px 画布，默认 12 词时已可能重叠，20 词更严重。
- 学习状态按数组下标记录，增删和排序后容易串词。
- 每个节点长期显示两个评分按钮，视觉拥挤，且隐藏释义前也能直接标记。
- 节点不是标准按钮，缺少键盘焦点、可读标签和足够触控区域。
- 保存失败后缺少明确重试出口。

### 3.5 同步边界不能凭假设处理

桌面 `SyncData.wordBook` 当前直接合并三张表；移动端当前同步代码未见对应的词图收集与还原，不能按「双端已完整同步」设计。

新版字段进入同步后，旧客户端可能忽略字段后再次回写。首版优先采用「只新增可选字段、不重命名或删除旧字段」的向后兼容方式；同时增加格式版本和未知版本保护。若某项变更无法向后兼容，在保护覆盖前暂停新格式词图云同步，仅保留本地与文件备份，不能假设已发布的旧客户端会识别新版本号。

## 4. 导图页设计

### 4.1 中心类型与示例

| 类型 | 示例 | 展示口径 |
|---|---|---|
| 字母组合 `letters` | `old → fold/hold/cold` | 拼写联想，不宣称词源关系 |
| 词根 `root` | `port → import/export` | 经确认时显示中心含义，如「携带」 |
| 前缀 / 后缀 | `pre`、`tion` | 高亮当前词缀 |
| 发音 `phonetic` | `/əʊ/` | 表示包含相同音素，不称「都是同音词」 |
| 自定义 `text` | 用户命名 | 仅表示自定义分组 |

`old` 示例可以保留，但必须从「词根 old」改为「字母组合 old」。`port/spect` 可继续作为词根示例。

### 4.2 页面容量

- 建议每页 6～10 词，软上限约 12 词。
- 超出时提示用户拆分，不继续增加节点密度。
- 旧页面超过上限时提供列表辅助，不通过缩小字体强行展示。
- 不机械地把筛选结果按固定数量切完就视为编排完成；自动分页只产生草稿。

### 4.3 布局规则

- 保留中心辐射构图和连线，不做自由坐标编辑器。
- 节点顺序由内容顺序决定，增删后自动重排。
- 根据容器宽高、节点数和节点尺寸计算椭圆半径及位置。
- 空间不足时扩大可滚动画布，不把正文缩到难以阅读。
- 新增 `src/utils/word-graph-layout.ts` 纯函数，输入容器与节点信息，输出坐标；不在 DOM 中散落布局计算。
- 对 1～12 节点、常见 uTools 窗口宽度、长单词场景做边界与重叠测试。

### 4.4 节点与详情

查看模式下节点只保留单词、必要音标和简短释义；完整内容进入侧边详情或抽屉：

- 完整释义、音标、发音；
- 当前中心在单词中的高亮；
- 页面备注；
- 编辑、移动、移除等操作按模式显示。

SVG 连线仅作视觉辅助，对屏幕阅读器隐藏。节点使用可聚焦按钮语义，支持 Tab、Enter、Space。

## 5. 三种页面模式

### 5.1 查看

- 默认显示释义和音标。
- 单击节点查看完整详情。
- 上一页、下一页连续学习，不必反复返回目录。
- 「标记已读」由用户主动操作，打开页面不自动记为已读；已读只用于阅读进度，不创建复习计划。
- 不长期展示逐词评分按钮。

### 5.2 复习

- 保留导图结构，仅隐藏释义。
- 用户先回忆，点击展开后才能选择「记住了 / 还没记住」。
- 评分操作集中在当前节点详情区，不铺满全图。
- 「还没记住」进入本轮末尾重看队列；再次答对也不删除首次错误历史。
- 本轮状态按 `entryId` 记录，不使用数组下标。
- 本轮草稿本地保存，刷新或短暂离开后可恢复；不同步、不分享。

结束页不强调分数，展示：

```text
本轮完成：共 8 词
首轮想起：6 词
重新回忆：2 词
```

### 5.3 编辑本页

在同一张导图上进入编辑状态：

- 修改页名、中心类型、中心文本和解释。
- 从当前词库搜索并添加单词。
- 移除节点，仅影响本页，不删除词库单词。
- 上移、下移调整顺序；拖拽排序后置。
- 修改本页释义、音标或备注，不回写原词库。
- 移动单词到其他学习页。
- 页面过大时拆分为新页；合页功能后置。

编辑使用草稿，提供保存、取消和离开未保存提示。清空所有词时引导删除页面，不保存空页。

## 6. 编辑后学习记录规则

| 操作 | 学习记录处理 |
|---|---|
| 调整顺序 | 不变 |
| 修改释义、音标、备注 | 不变 |
| 修改中心或页名 | 不变 |
| 新增单词 | 提示「内容有更新 / 有新增词」，不强迫整页重学 |
| 移除单词 | 当前页移除，历史轮次不改写 |
| 拆分页面 | 原页保留记录，新页从未学习开始 |
| 移动到其他页 | 作为目标页的新内容，不复制整页进度 |

编辑与学习不能同时进行；进入编辑前先结束或暂存本轮。

不建立第三套逐词独立 SRS。页面只保留页级复习和本轮错词，不与主词库、词集页级调度互相覆盖。

## 7. 页级状态与复习

建议状态由现有字段计算，不新增一堆手工维护的状态枚举：

- 未读 / 未学习；
- 已读但尚未进行复习；
- 学习中；
- 本轮已完成；
- 内容有更新；
- 待复习；
- 未到复习时间。

「已读」只表示浏览过内容，「已完成」只表示完成过一轮复习，两者都不表示永久掌握。

调度规则先保持简单并可测试：

- 新页面在复习首轮完成前不计入到期复习，仅查看或标记已读不创建复习计划。
- 首轮及到期复习无错：等级升 1，按现有间隔数组安排。
- 有错：不升级，等级不直接降 4；下次复习间隔取「当前等级间隔与 1 天的较小值」，让错词尽早重现。
- 额外练习默认只记录结果，不改变正式 `nextReviewAt`。
- 已读时间、轮次完成时间、最近学习时间和内容更新时间分别记录。

后续根据真实使用数据再调整算法，不在本期引入复杂评分模型。

## 8. 数据结构与迁移

本期不建设重型出版系统，也不急着拆分所有数据表。保留书、章、页文档，但在逻辑上区分内容和学习记录。

### 必要调整

`WordBookWord` 增加稳定的 `entryId`：

- 新条目创建时生成。
- 老数据迁移时确定性回填并保存，不能每次加载随机生成，避免多端 ID 漂移。
- 隐藏、标记、错误历史、编辑选择均使用 `entryId`。

`WordBookKey` 增加 `letters` 类型，并允许可选的中心解释。

页面增加或明确：

- `contentUpdatedAt`：内容编辑时间，用于提示更新，不与学习完成时间混用。
- 本轮/上轮摘要：首轮错误 `entryId`、重看数量、完成时间；不保存逐词独立复习等级。
- 编辑只更新内容字段，保留学习字段；分享时只导出内容字段。

### 保存可靠性

- store 创建和编辑方法必须返回保存结果，失败不能返回成功对象。
- 批量创建检查每项结果，失败时保留可恢复草稿并显示实际成功数量。
- 编辑保存失败不丢弃当前草稿。
- 本轮成绩保存失败提供直接重试，不要求重新开始。

## 9. 与主词库的边界

- 从词库加入时复制词条快照和来源信息。
- 从词集移除不删除词库单词。
- 修改词集释义不修改词库。
- 删除词库单词不级联删除词集快照。
- 词集学习不自动修改主词库等级、`remember` 或复习时间。
- 两边到期数量与完成进度分别展示。
- 「刷新自词库」「把错词加入主复习列表」只能作为用户主动操作，后续实现。

单词列表的「生成学习页」改为「加入词集」，作为快捷入口；词集内部必须具备完整创建和编辑能力。

## 10. 示例词集

示例只负责立即可用和教学：

- 提供「词根册」「词缀册」「拼写组合册」「场景名词」四本，共 73 个学习页。
- 「词根册」按 21 个词根分「核心词根」与「进阶词根」两章，核心词根是 act、form、port、pos、gen、fer、vis、spect、dict、ject；进阶词根是 mit、miss、duct、tract、struct、vid、geo、graph、phon、audi、bio。排序优先高频、简单、派生多的词根。
- 「词缀册」分「常用前缀」「常用后缀」两章，按使用频率和简单程度排序（un-、re-、dis-、pre-、ex-、inter-……；-er、-ly、-tion、-able……）；inter 页之后紧跟 interact 派生页，展示 inter → interact → interaction/interactive 的两层构词。
- 「拼写组合册」分「元音组合」「辅音组合」「特殊拼写」三章：元音 ea、ou、ai、ee、ow、oo、ay、oa、igh；辅音 ch、th、sh、ng、ck、qu、ph、wh；特殊 old、kn、wr、mb、tch、dge，中心解释带 emoji 图片联想。
- 「场景名词」按身体、日常物品和酒店场景分章。
- 每个学习页带构词/演变说明（页面 note，详情面板显示），关键派生词带词条 note（如 interaction = interact + -ion）。
- 词根/词缀/字母组合页内单词按词频从高到低排序，先出现最常用、最简单的词；自定义主题页保留人工顺序。
- 示例词集的详细书名、章节、排序规则、字段、ID/版本和复现方式见 `docs/wordbook-sample-books.md`。
- 示例可直接查看、编辑和删除，首次内容修改后归入「我的词集」；阅读、复习和删除不转换所有权。
- 用户删除或编辑示例后不自动复活，只能在「添加词集」的内置示例列表显式重新添加。
- 从内置列表打开同名现有词集，不重复创建副本。

不追求出版级审校，但明显的类型错误仍必须避免；只做非空、重复词、字段完整和 JSON 结构等轻量校验。

已有 `sr_wordbook_samples_v1` 标记的用户不得因版本升级重新生成已删除示例。升级 `v2` 时只替换仍为示例的旧「示例词集」：先完整创建新示例，成功后再删除旧数据；旧示例已删除或归入「我的词集」则不补建。`v3` 只服务全新用户，显式重新添加走内置示例列表。

## 11. 分享设计（核心流程稳定后实施）

先做内容副本分享，不做在线社区。

### 导出

- 支持整本词集，随后可扩展单章、单页。
- 文件包含格式版本、书章页、中心类型、词条、释义、音标、备注和顺序。
- 默认剥离学习进度、复习时间、最近阅读位置、个人笔记及无关本地 ID。
- 必要的数据来源与许可信息随内容保留。

### 导入

- 仅接受结构合法的 JSON，限制页数、词条数和字符串长度。
- 导入后成为接收方可编辑的副本。
- 重新生成书、章、页和 `entryId`，避免与原作者数据冲突。
- 失败不写入半成品，并给出可读错误。

暂不做账号、公开链接、点赞、关注、作者更新订阅或在线内容审核。

## 12. 首页与样式细节

### 首页

优先级依次为：继续学习、示例词集、我的词集；「添加词集」统一承载新建、导入与内置示例。

卡片展示书名、简介、页数、学习进度和最近更新，不再突出「第几关、每关几页」。管理操作进入次要菜单。

### 样式

- 沿用 `--utools-*` 与 Element Plus 主色变量，不另起高饱和配色。
- 中心节点只使用一个主色强调；当前共享字母、词根或音素使用语义色，不给整页 rainbow 着色。
- 查看页正文与释义建议至少 14px，次级文字保持可读对比度。
- 节点操作支持键盘焦点；触控/点击目标按不小于约 44px 设计。
- 状态同时用文字和颜色表达，不仅靠绿边、黄边区分。
- 动画只做 150～200ms 状态反馈，不做节点漂移、物理布局或庆祝特效。
- 在 uTools 最小常用窗口、宽窗口和暗黑模式下分别验证。

## 14. 测试与验收

### 标准检查

```bash
npm run test:run
npm run type-check
npm run build
```

涉及移动端防御性同步改动时，追加：

```bash
npm run type-check:mobile
npm --prefix mobile run type-check:test
```

### 必测逻辑

- 自定义页名实际生效，目标书章正确，锁定上下文不被重置。
- 保存失败不会提示成功，也不会造成不可恢复的半批数据。
- `entryId` 迁移稳定，排序和增删后学习状态不串词。
- 复习模式可展开或收起释义并切换记住状态；先错后对仍保留首轮错误。
- 新页面未学习不进入到期；额外练习不改变正式复习时间。
- 编辑释义和排序不重置进度；新增词仅提示内容更新。
- 导出不含个人进度，导入生成新 ID，损坏文件不产生半成品。
- 未知同步版本不会被旧客户端回写覆盖。

### uTools 实测主链路

1. 打开示例词集，两次点击内看到 `old` 导图。
2. 查看 `/əʊ/` 页面，点击节点看详情，连续翻下一页。
3. 从单词列表加入词集，修改页名并保存到正确章节。
4. 在导图里添加、移除、排序和修改单词，再进入复习。
5. 先错后对，确认结束页显示重看记录而非虚假 100 分。
6. 中途离开后恢复本轮，保存失败后可直接重试。
7. 导出词集并重新导入，确认内容可编辑且学习记录未泄露。
8. 在最小常用窗口和暗黑模式下完成一轮，确认无节点重叠、键盘可操作。

## 15. 明确不做与需要规避

- 不把「全部点完」当成永久掌握，不用虚假分数驱动激励。
- 不把字母组合硬称为词根，不把相同音素称为全部同音。
- 不把任意筛选结果机械分页后直接当成精心编排内容。
- 不用固定大画布、缩小字体或更多节点解决容量问题。
- 不在本期做通用自由关系图、手工坐标、复杂图编辑器。
- 不建立词集逐词独立 SRS，不静默写回主词库。
- 不在编辑时重置整页学习记录，不用数组下标关联学习状态。
- 不让示例更新覆盖用户内容，不让删除的示例自动复活。
- 不让分享文件默认携带学习记录，不做未校验的导入写入。
- 不因产品改名而批量迁移路由、DB 前缀和同步字段。
- 不在核心流程稳定前投入关卡、排行榜、公开社区和移动 UI 移植。

## 16. 本期完成定义

当用户能够在 uTools 中独立完成「查看示例 → 创建词集 → 在导图中编排 → 复习 → 保存并继续学习」，且数据保存、编辑进度、错误历史和同步版本保护均通过测试，即完成本期核心目标。

分享、激励和移动端移植均以该核心流程稳定为前提，不反向阻塞首版。

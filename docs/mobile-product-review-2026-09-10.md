# 移动端产品体验全面审查

> 2026-09-10。基于对移动端全部 34 个页面（4 tab + 30 子页）源码级交互审计。
> 与 `mobile-feature-redesign-2026-09-09.md`（功能取舍）互补：那篇管"做什么"，这篇管"做得顺不顺"。

## 〇、一句话诊断

骨架（tabBar/今日任务区）是对的，但**核心学习动作上埋着几个"bug 级"的交互硬伤**，模块之间互不推荐、激励机制近乎空白、五套配色各自为政。当前状态像"功能合集"，还不是"一个产品"。

---

## 一、反人类设计 / 必须修复的硬伤（P0）

这些不是"不够优雅"，是会真实伤害用户数据和信任的问题。

### 1. 左划"忘记"直接把单词打回 Lv1，且无 Undo
`review.vue` 的 `markAsForgotten` 无条件 `level = 1`——一个 Lv6 快养成的词，手指滑偏一次直接归零。且三个手势全部即时落库，**没有撤销、没有 toast 撤回、没有二次确认**。这是全 App 最高频页面上的最高危操作。
→ 修复：忘记应降 1~2 级而非归 1（与 store 里 `updateWordLevel` 的降级逻辑对齐）；完成弹窗或浮动条提供「撤销上一张」（保留最近一次的判定快照即可）。

### 2. 拼写练习 7 级 = 复习体系 12 级，口径冲突
拼写页把 `level >= 7` 标记 `remembered=true` 移出复习队列，但主复习体系要 Lv12 才算记住。用户会困惑"我的词练着练着不见了"。
→ 统一为 store 的 12 级标准，拼写练习只负责升降级，不做"毕业"判定。

### 3. 复习空态的「开始复习」实为强制全库复习
"还没到复习时间"时空态里的按钮会把全库所有词强制置为待复习，绕过遗忘曲线，按钮文案毫无提示。
→ 文案改为「提前复习全部 N 词」并加确认，或默认引导去拼写/听词等"不污染 SRS"的替代动作。

### 4. 错题本"已掌握"导致跳词
错题答对后词项立即从列表消失但索引不回退，连续操作会跳过词或显示空卡片。
→ 遍历快照而非活列表，或出列时回退索引。

### 5. 专注模式超时静默判"没记住"
自动翻页开启时，超时未操作的词按「没记住」写入 SRS，界面无倒计时、无提示——用户莫名被降级。
→ 超时词应记为"跳过"（不写 SRS），或至少显示倒计时环。

### 6. 新用户首页显示「🎉 全部搞定」
零单词新用户第一眼看到"今日已完成/太棒了"，与事实完全相反，还错失了引导导入词库的最佳时机。
→ 区分"词库为空"与"今日已学完"：前者显示「从导入一个内置词库开始」一键引导。

### 7. 其余静默失效/死胡同（批量修）
- 「点选拼写」对 >8 字母单词静默回退打字模式，无任何提示
- 添加单词：释义框有半个字时点「翻译」静默 return；同词可重复添加；「全部功能」页"添加单词"实际落在单词 tab 而非添加页
- 拼写练习空态、错题本空态均无出口按钮（死胡同）
- 拼写页静默过滤非纯英文条目——词库只有词组时用户看到空态却不知原因
- 知识库「已导入」灰徽标其实可点=移除，无任何可点暗示
- 词库列表"点一下即切换当前库"无提示、无 toast 反馈

## 二、不够无脑：认知负担清单（P1）

### 1. 术语体系混乱（最伤"无脑"）
同一动作在不同页面有 5 种叫法：**拼写 / 听写 / 半提示 / 点选 / 全盲**（dictation 与 focus 两页互相打架）；记忆宫殿的**桩 / 巡视 / 挂载**、知识库的**有序 / 翻卡 / 拼答案**、音标的**最小对立对 / 音素拆解 / 清浊**——全是行业黑话，无一句人话解释。
→ 统一动作命名表（全 App 一份）：看词回忆=「复习」、看义拼词=「拼写」、听音写词=「听写」、碎片拼答案=「拼答案」；黑话一律换口语：桩→「记忆钩子」、巡视→「过一遍」、最小对立对→「辨音」；每个模式第一次出现时给一句副标题说明。

### 2. 首页入口仍冗余
今日任务区 + 统计卡 + 快速宫格共 16 个可点入口，"复习"出现 3 次、"打卡"出现 3 次。
→ 首屏收敛：主任务卡只留一个主动作（开始复习）；统计卡保留可点但视觉弱化；宫格与任务区去重。

### 3. 路径过深
知识库要"导入 → 进详情 → 选模式"三层才到第一道题；新用户加词要走"单词 tab → +"（首页无添加入口）。
→ 知识库内置包支持「直接开练」（未导入则一键导入并进入）；首页任务区空词库时的主按钮就是"导入词库"。

### 4. 选择没有默认值
拼写页底部 5 个开关一排摆开；知识练习三模式无推荐逻辑。
→ 按场景给默认组合并隐藏进阶开关（"练习设置"折叠）；练习模式按包类型推荐默认项（公式包默认拼答案、元素包默认四选一）。

## 三、不连贯：模块孤岛（P1）

学习产品的心流是"学完 A 顺手到 B"，当前几乎全靠用户自己想起来：

| 断点 | 现状 | 应该 |
|---|---|---|
| 文本记忆 | 只能存/看/改/导入，**没有任何背诵玩法**（源码注释明示不实现填空/选择） | 至少加「遮挡回忆」（逐段遮罩点击揭示）这个零键盘玩法 |
| 数字记忆 | 建完 100 个桩**没有任何自测题型** | 加「报数字→回忆桩」翻卡（数据全有，只差题型） |
| 记忆测评 | 分数退出即丢，不推任何训练 | 结果页推荐对应训练模块 |
| 文本导入完成 | toast 后返回，不知东西去哪了 | 「去背第一篇」按钮 |
| 知识练习完成 | 只能再来一轮/返回 | 推荐同类包（学完元素表 → 化学方程式） |
| 翻译 OCR 取词 | 逐条加词库，无批量 | 全选/批量加入 |
| 发音 | 复习翻卡页、单词列表页都不自动发音（TTS 缓存能力白做了） | 复习页翻面自动发音 + 开关 |

唯一做对范式的：**主复习完成页**（统计 + 练拼写/看错题/去打卡的条件引导链）——这应该是所有模块完成页的统一模板。

## 四、奖励机制：近乎空白（P2）

现状盘点：连续打卡（无里程碑）、一张不主动弹出的分享卡、静态 🎉 emoji、线性进度条。没有积分、成就、目标、升级反馈、震动反馈。留存钩子只有 streak 单点。

**建议的轻量激励体系（不做账号、不做排行榜，纯本地）：**

1. **每日目标环**（最高优先）：首页主卡从"待复习 N 词"升级为"今日目标 M 词 · 已完成 N"的进度环，目标值可设（默认 20），完成时庆祝动画 + 自动弹出分享卡。这是把"任务感"变成"达成感"的最小动作。
2. **升级即时反馈**：单词 Lv 升级时卡片角落飘「Lv5→6」微动画；答对/答错加 `uni.vibrateShort` 触感（计划里早有，未落地）。
3. **里程碑成就**（本地解锁，~10 个）：连续 7/30/100 天、累计复习 500/2000 词、首个词库学完、错题清零。解锁时底部弹成就条，打卡页设"成就墙"。
4. **完成页统一庆祝模板**：所有练习完成页替换为复习页范式 + 一句随机鼓励文案 + "比上次多对 X 题"（历史成绩落库）。
5. **断签挽回**：连续打卡中断后首次打开给"重新开始"的正向文案而非从零的挫败感。

## 五、视觉与一致性（P2）

AGENTS.md 规定护眼绿主色、禁蓝色系，实际五套配色并存：音标/知识/数字记忆用 `#667eea` 紫蓝、记忆测评橙色渐变、错题本红橙渐变、翻译页 `#1976d2` 蓝。功能像五个外包做的。
→ 全站统一 token 化：主色 `#52796f`、语义色只留 success/warning/danger；错题本红橙渐变改为"护眼绿底 + 红色仅作语义点缀"。

## 六、冷启动（P2）

无引导页、默认词库为空、首个学习行为要 3 跳自发现。
→ 首次启动一次性引导：三屏（能做什么 → 选内置词库一键导入 → 直接开始第一次复习）。不做账号体系，保持"打开即用"。

---

## 七、优先级路线图

**P0 修硬伤（1-2 天量）**：忘记降级+撤销、等级口径统一、空态强制复习提示、错题跳词、专注超时静默判忘、新用户首页文案、各静默失效点
**P1 无脑化+连贯（3-5 天量）**：术语统一表、首页入口去重、文本记忆遮挡回忆、数字桩自测、复习页自动发音、各完成页接入引导链模板、知识库直接开练、OCR 批量入库
**P2 激励+视觉（3-5 天量）**：每日目标环、升级反馈+震动、里程碑成就、完成页庆祝模板、全站配色统一、首启引导

原则不变：一步能到不两步、能不打字不打字、不依赖系统不给的能力、桌面密度不照搬。

# 密钥代理必要性分析（2026-11-17）

## 背景

- uTools 商店审核后：商店版经 `__STORE_BUILD__` 置空全部内置密钥，默认免费引擎（B站）兜底，用户自填 key。
- 曾评估用云函数 / 自有服务器做密钥代理恢复「零配置」，当时决定暂缓。
- 本文回答两个问题：① 密钥代理有没有必要做；② Web 端与小程序端要不要跟进处理。

## 一、密钥代理：当前不必要

**收益**：任意端零配置开箱即用，且密钥不出现在客户端包里。

**代价**（按真实影响排序）：

1. **防滥用成本才是主成本**。代理一旦公开，等于把密钥变成公共免费接口——必须做安装凭证、限流、配额，否则被盗刷比明文密钥更快。明文密钥至少还要拆包，公开代理一个 curl 就能打。
2. 运维面：服务器只有一年（到期/迁移要动 DNS 与代码里的地址），可用性变成翻译功能的硬依赖。
3. 费用反而不是问题：一次翻译一次调用，当前量级（统计刚上线，日活极低）在云函数免费额度内。

**当前结论**：不做。已有免费引擎兜底默认体验，自填 key 是一次性配置。

**触发重估的条件**（满足任一再看）：

- 日翻译调用持续增长到自填 key 成为反馈里的主要流失点；
- 免费引擎失效或被风控；
- 已有服务端基础设施（备案域名 + 长期服务器）就位，加代理只是顺手。

## 二、Web 端：必须处理，但不是上代理，是同策略置空（已执行）

2026-11-17 实际验证发现两个叠加问题：

1. **启动崩溃级 bug**：`vite.config.web.ts` 从未 define `__STORE_BUILD__`，构建产物里保留字面标识符，页面启动即 `ReferenceError`。下一次 web 构建就是坏的。
2. **密钥公开**：web 构建内嵌全部密钥（已在产物中 grep 到阿里 LTAI 密钥）。Web 是公开部署，等于把审核问题 #2 原样放到公网，且没有审核方拦截。

**处理**（2026-11-17）：`vite.config.web.ts` 注入 `__STORE_BUILD__: 'true'`，与商店版同策略——不打包内置密钥（必应网页版同步隐藏），默认免费引擎，用户自填 key。一处改动同时修掉崩溃与泄露。

## 三、小程序端：同样暴露，建议跟进，但有用户体验折损

- `mobile/src/config.ts` 的 `DefaultApiKeys` 明文内嵌有道/百度/阿里（LTAI）/腾讯（AKID）/GLM 全套密钥，无任何条件。
- 消费方式是**静默兜底**（`translation-settings.ts`：用户没存 key 就用内置的）。置空后，从未配置过 key 的老用户升级即失去这些引擎（默认引擎 glm 也在其列），需手动配置。
- 小程序包可反编译；微信机审目前不查这个，但 LTAI/AKID 是云账号级凭证，泄露即盗刷。

**建议**：跟进置空（与 web/商店统一策略），时机放在密钥轮换之后——旧密钥作废、新密钥不再进仓库。若担心老用户体验，可在置空的同时把「翻译设置」入口做得更显眼。

**已落地的补强（2026-11-17）**：免费降级链新增 **MyMemory**（官方公开 API、免 key、国内可直连且 `ACAO:*`、支持句子）。桌面链：`…Google → MyMemory → Bing → GLM`，Web 链：`B站 → Google → MyMemory → GLM`。置空后「不想配 key」的兜底从单点 B 站变为国内外双点；仍想要更高质量时，引导用户花 2 分钟注册智谱 GLM 免费 key。

**更彻底的方向**（后续可选）：所有端的新密钥一律不进仓库，放 git-ignored 本地配置文件，发布构建天然无密钥，自己用的构建才有零配置。

**执行记录（2026-11-20）**：

- **密钥暂缓置空（用户决定）**：`mobile/src/config.ts` 的 `DefaultApiKeys` 保留原内置密钥，等完成轮换后再执行置空；默认引擎仍为 GLM，老用户零配置体验不变。
- 保留本轮已做的低风险增强：MyMemory 免费引擎（可选，且未配置 key 的在线引擎自动回落）、AI 单条翻译鉴权修复（`appkey` = Token、`key` = 模型名，原先用反导致配了 key 也可能失败）、OCR 缺 key 的可操作提示、中文发音百度 TTS 兜底。
- 微信公众平台合法域名：request `api.mymemory.translated.net`、downloadFile `fanyi.baidu.com`（配置后免费引擎与中文朗读才可用）。
- 后续待办：① 到各云厂商控制台轮换/作废旧密钥；② 轮换完成后置空 `DefaultApiKeys`；③ 真机走查翻译/OCR/中文朗读/设置弹窗。

## 四、Electron / 抖音 / App

按平台优先级（见 AGENTS.md）保持现状：Electron 补 `__STORE_BUILD__: 'false'` 宏仅修启动崩溃，密钥保留（自有渠道分发、无审核要求、低优先平台）。抖音/App 未涉及密钥链路，不动。

# 慢记工具 · 系统学习教程

一句话：慢记帮你把「要学的东西」按遗忘曲线安排到最该复习的时刻出现——你只需要每天花几分钟把到期的内容过掉。

本教程回答四个问题：**怎么开始、从哪开始、每天怎么用、怎么用得更快**。

---

## 一、怎么开始：5 分钟上手

1. **安装**（任选一端）：
   - 电脑：安装 [uTools](https://u.tools/) 后在插件市场搜「慢记」；或下载 Electron 桌面版
   - 手机：微信/抖音小程序搜「慢记」
2. **打开**：电脑按 `Alt + 空格` 呼出 uTools，输入 `mj` 或 `慢记` 回车。
3. **收第一批内容**（三选一，30 秒）：
   - 在单词页点底部词库名 →「新建词库 → 从系统词库导入」，挑一个内置词库（如四级词汇）；
   - 或直接呼出 uTools 输入一个你想记的单词（如 `apple`），选「收进单词/句子库」；
   - 或去「文本记忆」→「＋」→「内置库」，勾选几首唐诗导入。
4. **完成第一轮复习**：列表里点「认识 / 忘记」，系统就开始为你排期了。

> 到此为止你已经会用了。后面是按目标进阶。

---

## 二、从哪开始：按目标选一条路

### 路径 A：学外语（英/日/俄/西/法）

语言学习按 **听 → 说 → 读 → 写** 闭环效果最好，慢记每个环节都有对应工具：

| 环节 | 用哪个功能 | 怎么做 |
|------|-----------|--------|
| **听** | 复习列表的发音按钮 + 音标学习里的「辨音练习」 | 复习时先听发音再看词；容易混的音（如 ship/sheep）去辨音练习二选一 |
| **说** | 复习时跟读 | 听一遍发音，出声跟读两遍，再点「认识/忘记」 |
| **读** | 每日「待复习」列表（看词回忆释义） | 这是主线，每天清空到期单词即可 |
| **写** | 拼写练习（单词页底部工具栏 ✏️ 图标） | 先开「给一半字母」提示，熟后关掉全盲默写 |

配套建议：

- 词库语言决定发音、音标、OCR 的全链路语言——学日语就建日语词库（内置 JLPT N5），界面自动切五十音。
- 碎片时间开「专注模式」悬浮窗挂屏幕角落，工作间隙瞄一眼。
- 阅读遇到生词：选中 → `hc`（划词添加）；图片/PDF 里的词：`ss`（截图添加）。

### 路径 B：背诗词、文章、成语

1. 「文本记忆」→「＋」→「内置库」：428 首古诗词、160 条成语、336 个历史时间线事件，勾选即导入。
2. 每篇文章的练习顺序：**通读 → 填空练习（自动挖空关键词）→ 跟打练习（逐字对照输入）**。
3. 长文背不下来：在记忆宫殿里把文章切块**挂载**到桩上，用空间位置辅助顺序回忆。
4. 通勤时用「专注显示」悬浮窗滚动播放，磨眼睛熟悉度。

### 路径 C：记长数字（电话号码、卡号、圆周率、历史年份）

1. 「数字记忆」→「数字-图片映射设置」→「一键导入预设」：给 0-99 每个数字配一个形象（如 15=鹦鹉）。
2. 回首页玩「数字 → 图片」「图片 → 数字」训练，把映射练熟（至少 4 个关联才能开始）。
3. 真实要记的数字（如手机号）建成「数字记忆条目」，两位一组转图像编故事，到期自动提醒复习。
4. 映射表可导出成图片打印，贴在桌前。

### 路径 D：应试背书（公式、常识、考点）

1. 「知识库」三类共 35 个内置包，按需在对应分类导入：
   - **数理化**：乘法表、数学/物理/化学公式、元素周期表、理化生实验、计量单位、质数表
   - **文史常识**：朝代、节气、生肖、民族、省会、三十六计、国家首都、地理概念
   - **桩库**：这组不是「知识」，是记忆宫殿的地基（见路径 E）
2. 练习节奏：先「Q→A 翻卡」过一遍混眼熟 →「四选一」检验 →「输入模式」严格校验拼写。
3. 顺序本身是考点的包（朝代、节气、三十六计）用「顺序回忆」。
4. 数学/物理公式条目带**函数图像**（拖参数看曲线变化），化学方程式带**现象动画**，先理解再背。

### 路径 E：练记忆方法（记忆宫殿）

记忆宫殿是公认最强的顺序记忆法，适合演讲稿、条文、考试大题：

1. 「记忆宫殿」→「新建」（如「我的家」）→「导入桩库」选「家居路线桩」，自动生成 12 个桩位。
2. **关键一步**：把每个桩的默认图换成你自己家对应位置的照片——越熟悉越牢。
3. 把要记的内容挂载到桩上：自由文本直接写，或把文本记忆里的文章按段落切块挂载。
4. 点「开始过一遍」：按桩位顺序回忆挂载内容，记住/忘记自评，系统按遗忘曲线安排下次。

## 三、每天怎么用：推荐节奏

| 时段 | 动作 | 耗时 |
|------|------|------|
| 早上 | 清空「待复习」（系统已筛好今天到期的） | 3-10 分钟 |
| 白天碎片 | 专注模式悬浮窗挂着；遇到生词随手 `hc` 划词收进 | 不占用整块时间 |
| 晚上 | 拼写练习巩固当天新词；新内容入库 | 5 分钟 |
| 周末 | 知识库/记忆宫殿过一遍长期内容 | 随缘 |

原则：**复习交给系统排期，你只负责每天清空到期队列**。新增不贪多，每天 10-20 个新词比一次灌 200 个记得牢。

## 四、怎么快：老手提速清单

**关键词直达**（uTools 呼出后输入）：

| 输入 | 直达 |
|------|------|
| `mj` / `慢记` / `review` | 单词复习列表 |
| 任意单词或句子 | 收进单词/句子库 |
| `hc` / 划词后呼出 | 划词添加 |
| `ss` / `截图添加` | 截图 OCR 取词 |
| 任意数字 | 数字记忆 |
| `翻译` / `fy` | 快速翻译 |
| `文本记忆` / `记忆宫殿` / `知识库` / `专注` / `快捷键记忆` | 对应模块 |

**单词页快捷键**：`Shift+R` 认识、`Shift+F` 忘记、`Shift+P` 发音、`Shift+T` 翻译、`Ctrl+Enter` 保存释义。

**专注模式快捷键**：`←/→` 切词、`↓` 永久记住、`Ctrl+L` 锁定穿透、`Esc` 关闭。

**其他提速**：

- 「☰」抽屉里常用入口会按你的使用频率自动上浮；
- 列表支持通配符搜索（如 `ab*t`）、长度/词根词缀筛选、多词库并行；
- 老人或大屏用户：设置（右上角「⋯」）→「界面字号」调到大档；
- 文本记忆列表的多选模式可批量打印/存图，方便做纸质卡片。

## 五、数据安全与多端同步

数据始终存在本地，同步是可选的。三种方式：

1. **云盘同步（坚果云，推荐长期备份）**：
   - 电脑登录 [jianguoyun.com](https://www.jianguoyun.com/) → 右上角账号 →「账户信息 → 安全选项 → 第三方应用管理」→ 生成**应用密码**（不是登录密码）；
   - 在慢记「多端同步 → 云盘同步」填坚果云账号（邮箱/手机号）+ 该应用密码，点「上传到云盘」；
   - 数据加密压缩后存为你云盘里的 `slowlyRecord-sync.enc`，换设备时填入同样账号密码「从云盘下载」即可。
2. **服务器同步码（一次性互传）**：设备 A「推送数据」拿到同步码，设备 B 输入同步码拉取。数据 AES-256 加密后过服务器，服务器只存密文。
3. **文件同步**：导出文件 → 任意方式传到另一台 → 导入。无网环境兜底。

> 注意：同步是「合并」不是覆盖——两端各自新增的单词会合并到一起。但**删除**目前也会合并保留（A 端删掉的词，B 端同步后会回来），彻底删除需在两端各删一次。墓碑式删除在路线图上。

## 六、遇到问题

- 完整功能说明书见 [README](../README.md)；
- 截图取词没反应/次数受限：设置里把 OCR 引擎切到「本地识别」（无限次、离线可用）；
- 翻译失败：默认引擎每日有免费额度上限，超限会自动降级到其他引擎，不急就明天再来，急就在设置里换一个；
- 数据异常：「多端同步 → 文件同步」先导出一份备份，再在「更多 → 数据」里排查。

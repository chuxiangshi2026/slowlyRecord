## 一、慢记是什么

慢记（slowlyRecord）是一个「慢慢记、记得牢」的记忆训练工具，把间隔重复记忆法做成开箱即用的工具。支持单词、古诗词等文本、数字、知识库等多种记忆对象，覆盖 uTools、Web、小程序多平台，数据可导入导出与同步。

## 二、记忆方法（为什么这样设计）

- **间隔重复**：按遗忘曲线在将忘未忘时安排复习（单词卡片上的待复习/已复习/已记完统计即来源于此）。
- **记忆宫殿 / 记忆桩**：把抽象信息挂到熟悉的空间路径上，见记忆宫殿模块。
- **字母映射 / 音标 / 快捷键记忆**：把难记序列转码为易记图像或声音（数字转码、音标辨析等）。

## 三、数据模块总览

| 模块 | 记什么 | 说明 |
| --- | --- | --- |
| 单词复习 | 英语单词、短语、句子 | 核心模块，支持从 uTools 输入框直接添加 |
| 文本记忆 | 古诗词、课文等长文本 | 逐篇收集、按标签/时间/地点/事件组织 |
| 数字记忆 | 数字序列 | 字母映射转码 + 关联图片 + 训练 |
| 句子库 | 收集的例句 | 复习单词时顺手收集 |
| 知识库 | 结构化知识 | 内置知识包（乘法表、元素周期表等）+ 自定义导入 |
| 记忆宫殿 | 任意知识的宫殿法管理 | 建宫殿、放记忆桩、走宫复习 |
| 音标学习 | 英语音标 | 音标表、识别练习、最小对立对 |
| 字母映射 / 快捷键记忆 | 数字编码表 / 软件快捷键 | 辅助训练模块 |
| 听写练习 / 快速翻译 / 记忆力测试 | 工具 | 翻译支持多种引擎，记忆力测试含 8 类数据 |
| 打卡 | 每日复习 streak | 🔥 连续天数 |

## 四、数据存储与同步

- 各端数据默认保存在本机（uTools 端存 uTools 数据目录，Web 端存浏览器本地库，小程序端存微信存储）。
- **同步与备份**：设置 → 同步与备份，可将个人配置与数据在多台设备间迁移；也支持导出/导入文件备份。
- 导出格式：单词支持 JSON / TXT 等格式（详见各端设置中的导入导出）。

## 五、常见问题

- **换新设备/新浏览器数据没了？** 数据默认只在本地，请先用旧设备导出或同步。
- **翻译不能用？** 设置 → API 密钥中配置翻译/OCR 引擎密钥（默认提供免配置通道）。

# uTools 端首页重设计计划（任务驱动版）

日期：2026-09-11（v2，评审后修订）
状态：方向已确认，待实施
范围：仅 uTools 插件端（桌面版/移动端不在本期）

## 一、设计背景与原则

uTools 插件的本质是**工具**：用户呼出插件是为了"立即干活"（复习、收词、翻译），用完即走。因此首页不做功能探索型导航（侧栏/网格入口），而是**任务驱动**：进来就是当前该干的事。

uTools 弹层原生已提供插件头（插件名 + 关闭）和设置图标，因此应用内头部**不放品牌名、不放设置**，只保留一行全局状态。

设计原则：
1. 一键添加单词是关键入口（划词/截图是收集主路径）
2. 首页空间给"当前任务"，不给"功能入口"
3. 头部只一行：全局状态（列表模式 + 打卡），不承担品牌与设置
4. 底部工具栏只留简单高频操作，低频全部收进「更多」抽屉
5. 打卡激励融入头部，复习即打卡，零额外操作
6. 头部是所有页面共享的全局导航锚点：页面名告诉用户在哪，「更多」衔接其他模块

## 二、页面结构

### 2.1 统一头部（一行，所有页面共享）

```
┌──────────────────────────────────────────────────────┐
│ 单词 · 待复习: 32 · 已复习: 0 · 已记完: 15    🔥 7 天 │
└──────────────────────────────────────────────────────┘
```

- **页面名**：当前模块名（单词/数字记忆/文本记忆…），是全局导航锚点
- **列表模式切换**（单词页专属位置）：原底部工具栏左侧的「待复习/已复习/已记完」上移至此，点击切换主区域列表，当前模式高亮，默认「待复习」。「单词总数」不占位，并入「筛选▼」面板底部
- **🔥 打卡**：连续打卡天数，点击 → `/sign` 打卡页
- **同步状态点**：正常时不显示；同步失败/有未同步改动时，🔥 旁浮现灰/红点，点击打开同步弹窗，恢复后自动消失（渐进呈现，不占常规空间）
- 其他页面此位置换成本模块的状态摘要（见 2.5），右侧为 🔥 + 「← 返回」
- 待复习为 0 时「待复习」显示 0 并附提示「今日复习已完成 🎉」

**为什么不放「开始复习」按钮**：通过关键字「慢记」进入主页时就已经是复习状态——主区域默认就是待复习列表，每张卡片上直接点「认识/忘记」就是复习动作，无需再一次"开始"。沉浸式逐个复习由底部「听写」（拼写检验）与「专注」（悬浮窗复习）承担。

### 2.2 主区域 = 当前任务（以单词页为例）

```
┌─────────────────────────────────────────┐
│ apple                                   │
│ /ˈæpəl/  n. 苹果          [认识][忘记]  │
├─────────────────────────────────────────┤
│ banana                                  │
│ /bəˈnɑːnə/ n. 香蕉        [认识][忘记]  │
└─────────────────────────────────────────┘
```

**空态（冷启动引导）**：无单词时主区域显示三张引导卡——「划词添加」「截图添加」「导入内置词库」（`public/wordbanks/` 现成数据）。空态是任务驱动首页唯一没有任务的场景，必须给出下一步。

**添加即时反馈**：划词/截图添加成功后，轻提示「已加入 xx 词库 · 今日待复习 +1」，与打卡激励形成闭环（添加也是打卡行为）。

### 2.3 底部工具栏（7 个，全部高频，单词页专属）

```
[词库▼] [⇅ 顶/底] [释义] [筛选▼] [听写] [专注] [更多▾]
```

| 按钮 | 说明 |
|---|---|
| 词库▼ | 切换/管理词库 |
| ⇅ 顶/底 | 置顶/置底合并为一个智能按钮：列表未滚到底部时点击滚到底部（显示 ⇩）；已在底部时点击回到顶部（显示 ⇧）。两者语义互斥，合并省位置且防误点 |
| 释义 | 显示/隐藏释义合并为一个开关 |
| 筛选▼ | 筛选排序面板（底部显示单词总数） |
| 听写 | 进入听写练习 |
| 专注 | 打开专注悬浮窗 |
| 更多▾ | 全部其他功能（见 2.4） |

移除：导入/导出、同步、设置、字母映射、音标（全部入"更多"）、待复习/已复习/已记完切换（上移头部）、置顶/置底双图标（合并）。
其他模块页面**不带底部工具栏**（释义/筛选/听写只对单词有意义）。

### 2.4 「更多」抽屉（13 项，全部 ≤ 2 次点击可达）

```
┌─────────────────────────────────────┐
│ 记忆训练                            │
│   数字记忆      今日已训练 3 次      │
│   文本记忆      《静夜思》还剩 2 段  │
│   知识库        数学公式 待复习 3    │
│   句子库        已收集 12 句         │
│ 工具与评估                          │
│   快速翻译                          │
│   记忆力测试    上次: 3 天前         │
│ 辅助                                │
│   字母映射 / 音标学习 / 记忆宫殿 / 快捷键记忆 │
│ 数据                                │
│   导入 / 导出                        │
│   同步与备份    上次同步: 今天 10:23 │
│   设置          翻译引擎 · API Key · 快捷键 │
└─────────────────────────────────────┘
```

- 每项带一句话状态（有数据时），降低"这是什么"的认知成本
- **知识库**为独立入口：知识包（函数图像、公式、实验/场景演示）横跨数字/文本两个模块，现在藏在文本记忆的知识包面板里不好找；点击进知识包列表页，再进 `/knowledge-memory/:id` 练习页
- 抽屉条目尽量从路由 meta（title/icon）生成，避免两处维护菜单
- 「同步与备份」打开 SyncDialog；「设置」打开设置抽屉（原 DetailDrawer 的设置区）

### 2.5 其他页面 = 同构骨架（换头不换身）

所有模块页面共用骨架：统一头部一行 + 主区域当前任务，无底部工具栏，头部右侧「← 返回」。

| 页面 | 头部状态摘要 | 主区域 | 改动量 |
|---|---|---|---|
| 数字记忆 | ⏰ 3 条到期 · 今日已练 3 次 | 训练模式卡片（数字→图片 / 图片→数字 / 随机序列 / 映射设置） | 现状已是卡片式，仅换头 |
| 文本记忆 | 《静夜思》还剩 2 段 | 文本列表 + 继续背诵；添加/导入走 TextImportDialog | 仅换头 |
| 知识库 | N 个包 · 待复习 M 条 | 知识包卡片列表（进度条 + 待复习数），点进练习页 | 现 KnowledgePackPanel 提升为独立页 |
| 句子库 | 已收集 12 句 | 搜索 + 标签筛选 + 句子列表 | 仅换头 |
| 快速翻译 | — | 输入框 + 结果卡片 | 仅换头 |
| 记忆力测试 | 上次: 3 天前 | 4 模式（数字/单词/图案/词汇量）+ 难度 + 开始 | 仅换头 |
| 打卡页 | — | 连续/累计/本月统计卡 + 12 周热力图 | 现状已有，仅换头 |
| 听写 | 待复习: 32 | 听写卡片流（保留页内待复习/已复习切换） | 仅换头 |
| 字母映射 / 音标 / 记忆宫殿 / 快捷键 | — | 各自工具页 | 原样 |
| 专注 | — | 独立悬浮窗 | 不走本骨架 |

**不动的部分**：知识包练习页内部（函数图像 FunctionPlot、latex 公式、实验/场景演示），文本记忆页内视图（诗词地图 PoetryMap、时间线 TimelineView、关系图 RelationGraph、地图定位）——都是模块内部页面/视图，本期原样保留。

### 2.6 关键交互决策（评审记录）

1. **待复习/已复习去哪了**：上移头部一行。它们是"全局状态 + 列表筛选"，放头部比底部工具栏更符合阅读习惯；「总数」并入筛选面板。
2. **「开始复习」是不是别的模块**：不是，是冗余设计，已取消。进入主页即复习态，卡片上的认识/忘记就是复习动作本身。
3. **置顶/置底为什么合并**：语义互斥（在顶部时"置顶"无意义），合并为按滚动位置智能切换的单按钮。
4. **头部为什么不放品牌/设置/同步**：uTools 原生弹层已有插件头；设置为"配置一次不动"的低频项，入「更多」；同步入「更多」但保留异常状态点。
5. **键盘快捷键**：复习操作已有完整快捷键，本期不涉及。

## 三、关键词入口（10 个 feature 保留，行为收敛为 5 类）

低频功能的关键词不删除——它们本身是 uTools 搜索入口，且页面本来可达，关键词只是更方便的直达方式。

| 关键词 / feature | 行为 |
|---|---|
| 慢记 / review | 进主页面（默认待复习列表，即复习态） |
| 加入单词簿 / over | 收集单词/句子到词库（长文本自动分流句子库） |
| 划词添加 / huaci | 同上（原「划段添加 / huaduan」并入，按文本长度自动判断） |
| 截图添加 / jietu | OCR 识别到词库（含 img 类型直接触发） |
| 翻译 / translate | 快速翻译页 |
| 专注 / focusMode | 直接打开专注悬浮窗 |
| 记忆测试/数字记忆/文本记忆/快捷键记忆 | 进主页面并直达对应模块页面 |

变更仅两项：huaduan 并入 huaci；直达类关键词统一走"主页面 → 对应模块"。

## 四、打卡激励

- **入口**：头部 "🔥 N 天" 点击进入打卡页（统计卡 + 12 周热力图，现状已有）
- **自动打卡**：任何复习/添加行为（`addAndUpdateWord`）触发 `signToday()`，已实现
- **即时反馈**：今日首次打卡时，头部天数 +1 并弹轻提示「已连续打卡 N 天」
- **复习提醒协同**：现有 `onPluginEnter` 系统通知（每进程一次）与头部待复习数重复触达，通知应可点击直达待复习列表（需确认通知适配器支持点击回调），否则弱化通知
- **跨端同步**：打卡记录已走 sync-manager 日期并集合并，后期小程序端共用同一结构

## 五、翻译引擎策略（按可用性排序）

免费引擎优先级链（额度耗尽/429 时自动降级到下一个）：

```
讯飞星火 → 有道 → 百度 → Google → Bing → 智谱GLM(兜底)
```

理由：GLM 免费但 429 频繁可用性差；讯飞（MaaS 免费模型）与有道等传统引擎可用性最高。

设置页配套弱化：
- 第一屏只显示当前引擎卡片：「讯飞星火（免配置 · 每日 500 次）」+「切换引擎」按钮
- 切换弹窗只列免配置引擎；付费引擎收进"其他引擎"
- 密钥配置区默认收起，标题改「高级设置（自定义 API Key）」
- 腾讯"即将下线"警告仅在选中腾讯时显示

## 七、验证方式

- `npm run type-check` + `npm run test:run` 全绿
- uTools 实测关键词路径：划词/截图/翻译/慢记/专注 + 直达类（记忆测试等）
- 头部打卡点击 → 打卡页 → 返回主页面，状态一致
- 工具栏移除的每个功能都能从「更多」抽屉到达
- 断网/429 场景下翻译自动降级链生效并有提示
- 空库新用户看到三张引导卡且均可操作
